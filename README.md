# Tik-Tok

مشروع خاص لبناء نسخة TikTok معدلة للجوال.

## الهدف الحالي
- TikTok 47.0.3
- Package: `com.zhiliaoapp.musically`
- Hushfeed 0.64.0
- تعريب إعدادات Hushfeed
- توقيع ثابت للتحديث فوق الإصدارات المعدلة السابقة بدون حذفها

## ملاحظة التوقيع
مفتاح التوقيع لا يتم حفظه داخل المستودع. يتم الاحتفاظ به خارج GitHub واستخدامه فقط عند توقيع APK النهائي.

## البناء
GitHub Actions يبني حزمة patches عربية `.mpp` من Hushfeed 0.64.0.
